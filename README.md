# 고고덕 아일랜드 · 캐치마인드

## 실행

`run-game.ps1`을 실행하면 브라우저가 열리고 게임 서버가 함께 시작됩니다.

친구와 테스트할 때는 PowerShell에 표시되는 `http://내IP:4173/` 주소를 친구에게 보내세요. 같은 와이파이 또는 같은 사내/집 네트워크에 있으면 방 코드로 함께 접속할 수 있습니다.

## 현재 구성

- 단어장: 1000개
- 1인 연습: 첫 화면의 `혼자 연습하기`
- 친구 테스트: WebSocket 서버 기반 실시간 동기화
- 동기화 항목: 참가자, 준비 상태, 게임 시작, 그림 선, 지우기, 채팅, 정답 처리

## 참고

외부 인터넷에 있는 친구와 테스트하려면 포트 포워딩, 터널링, 또는 배포 서버가 필요합니다. 지금 버전은 바로 테스트하기 좋은 로컬 네트워크용입니다.

## 인터넷 친구와 테스트하는 방법

가장 쉬운 운영 방식은 Render, Railway, Fly.io 같은 Node 서버 배포 서비스를 쓰는 것입니다.

- Root directory: 이 `catchmind` 폴더
- Build command: 없음 또는 비워두기
- Start command: `npm start`
- Port: 서비스가 제공하는 `PORT` 환경 변수를 자동 사용

배포가 끝나면 `https://...` 주소 하나가 생기고, 그 주소를 친구에게 보내면 서로 다른 네트워크에서도 같은 방에 들어올 수 있습니다.

임시 테스트만 할 때는 ngrok 또는 Cloudflare Tunnel 같은 터널링 도구로 `http://127.0.0.1:4173`을 인터넷 주소로 열어도 됩니다.
